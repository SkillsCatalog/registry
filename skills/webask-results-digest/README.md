# WebAsk Results Digest

A workflow for summarising and comparing WebAsk survey results.

Original publisher: [WebAsk](https://webask.io/).

- [Original English skill](https://github.com/WebAskio/webask-mcp/tree/main/en/skills/webask-results-digest)
- [Russian counterpart](https://github.com/WebAskio/webask-mcp/tree/main/skills/webask-results-digest)
- [Official MCP setup](https://webask.io/dev/api/mcp)
- [Full collection: 25 workflows in Russian and English](https://github.com/WebAskio/webask-mcp)

This distribution preserves the upstream workflow and MIT attribution and adds
catalog metadata, setup, examples and dependency notes. Public files are MIT
licensed. The hosted WebAsk service is separate and subject to its account plans
and limits. Each user supplies their own API key privately in their MCP client.

No credentials, respondent data, or hosted server implementation are bundled.
The catalog's static validation does not establish an authenticated runtime test.
